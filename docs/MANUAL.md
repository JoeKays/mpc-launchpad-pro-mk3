## Pages

- **Clip grid** (default): pads launch clips; Shift + pad selects without
  launching; an empty pad stops the track.
- **MPC pads mode** (Note): the bottom-left 4x4 mirrors the MPC pads for drum
  tracks; melodic tracks get 64 pads across the four banks.
- **Volume / pan / sends menus** (function buttons 4/5/6): each track column is
  a fader; press the button again to exit.
- **Q-Link page** (Device): eight faders per page, banks coloured by Q-Link
  group; press Device again for page 2, once more to exit.
- **Tempo page** (Shift + Device): Up/Down change the BPM.
- **Swing page** (Shift + Stop clip): Up/Down change swing, 50-75%.
- **Step sequencer view** (Sequencer): opens the MPC view; Shift = next bar.

## Journal

Every action logs a line through `print`, prefixed `LaunchpadProMK3:`.
Read it with:

```sh
journalctl -u acvs -o cat --no-pager | grep LaunchpadProMK3
```

## Guards

Project-scoped pages refuse to open while no project is loaded or a dialog
owns the UI (`engineMode.CurrentPopup` is not `No Popup`). Each refusal logs
once, for example `quantize: dialog open (New Project)`.
